# Community announcement — copy after publication

Before posting, confirm that the numbered release page has all three platform
downloads. Don't send people to a missing release or substitute the moving
development build. Adapt the text below to your own voice.

---

I've been building **Omazone**, a free, open-source mastering app for home
musicians, and I'd love some help testing it before 1.0.

Load a mix and a reference, try reference matching, EQ, compression and limiting,
compare at matched loudness, and export a WAV. Save your work and come back to it.
It's an offline desktop app, not a plugin or an automatic promise of a better master.

**Community beta: 0.4.0 beta 1**
https://github.com/marrabld/omazone/releases/tag/v0.4.0b1

Downloads: Windows x64, Apple Silicon Macs on macOS 14+, and Arch / Omarchy x86-64.
Windows and Mac builds are unsigned; installation notes are on the release page.
No paid account or Python installation is needed for the apps.

You don't need to be a developer or mastering engineer. Try a mix you know, save
and reopen a project, export a file, and tell me what happened. Confusing labels,
awkward workflow and "it worked on my setup" are useful feedback too. If you have
time, try ordinary versus range-aware matching, or the new loudness targeting.

Please use copies, save under new names and start with low monitoring volume.
There's no need to share your music publicly.

**Short testing guide:**
https://github.com/marrabld/omazone/blob/v0.4.0b1/docs/beta-testing.md

Reply here or use the GitHub feedback form in the guide. Include app version,
OS/device, what you tried, and what you expected versus what happened. I'll gather
the feedback, work through the problems, and ask for retests as we get ready for 1.0.

Thanks for giving it a listen.
