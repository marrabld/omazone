# Omazone 0.4.0 beta 1 — community testing

This is a community beta on the way to 1.0. Omazone is a free, GPLv3 desktop
mastering app for home musicians. Bring a mix and a reference, compare changes
at matched loudness, and tell us what works and what gets in your way.

**Start with the [beta testing guide](https://github.com/marrabld/omazone/blob/v0.4.0b1/docs/beta-testing.md).**
Use copies of recordings, save beta projects under new names and start at a low
listening level. This is not the stable 1.0 release.

## Since v0.3.0

- Measured reference variation: percentile envelope, median and density display.
- Optional range-aware matching alongside ordinary reference matching.
- Export-only conversion to 44.1/48/88.2/96 kHz, converted-rate review and
  measurements of the written file. Audition stays at source rate.
- Explicit LUFS/peak targeting: inspect a gain-only or existing-limiter proposal,
  then separately apply and render. No hidden export normalisation.
- README overview, feature guides and screenshots.

Existing tools include manual/dynamic EQ, corrective filters, broadband or
three-band compression, final limiting, saved recipes and 32-bit float / 24-bit
PCM WAV export. Range-aware matching isn't inherently better, and LUFS targets
are your choice rather than universal streaming requirements.

## Downloads and limitations

- Windows x64: extract the whole zip, then run `Omazone.exe`.
- Apple Silicon macOS 14+: extract `Omazone.app` and move it to Applications.
  No Intel Mac bundle.
- Arch / Omarchy x86-64: install the `.pkg.tar.zst` with `sudo pacman -U`.

Windows and macOS builds are unsigned. Read the
[platform notes](https://github.com/marrabld/omazone/blob/v0.4.0b1/docs/packaging.md)
for installation warnings and verification. Python is not needed for the bundles.
The files below are the beta snapshot; the rolling development build changes.

Automated checks don't prove playback on your hardware or good sound on your music.
Listening, device and small-screen reports are especially welcome. This is an
offline app, not a real-time plugin. Automation, stereo imaging and extra dynamic-EQ
bands aren't part of this beta.

## Feedback

[Report a problem or successful test](https://github.com/marrabld/omazone/issues/new?template=beta-feedback.yml),
or reply to the maintainer in the community thread. Include exact version, OS,
device/backend, steps, expected result and actual result. You don't need to be a
developer, share private music or own special hardware.

Reports will guide fixes and follow-up betas before 1.0. There is no fixed release
date; we want the core workflow to be dependable first.
